# 欢迎来到我的博客！

你好，世界！这是我博客的第一篇文章。

## 关于这个博客

这个博客使用 [Astro](https://astro.build) 构建，是一个现代化的静态网站生成器。Astro 具有以下特点：

- **快速**：Astro 默认生成零 JavaScript 的静态 HTML
- **灵活**：支持 React、Vue、Svelte 等多种框架
- **强大**：内置 Content Collections 功能，方便管理内容

## 为什么选择 Astro？

1. **性能优先**：Astro 采用岛屿架构，只在需要时加载 JavaScript
2. **开发体验好**：支持 TypeScript、MDX 等现代工具
3. **SEO 友好**：生成静态 HTML，对搜索引擎友好
